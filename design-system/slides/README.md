# Slide templates

Four 1920 × 1080 slide layouts lifted from the JHO brand deck, each in its own file and scaled
to fit a 1280 × 720 card.

| File | Layout |
| --- | --- |
| `TitleSlide.html` | Cover — eyebrow rule row, full-bleed wordmark, mosaic rule, meta footer |
| `ConceptSlide.html` | Two-column — display lead statement left, numbered pillars right |
| `SpecSlide.html` | The house workhorse: headline + eyebrow over a 1px rule, then a two-column body |
| `SummarySlide.html` | Eight newsprint cards in a 4 × 2 grid |

**The rule to keep:** every slide except the cover opens with a headline left, an eyebrow right,
and a 1px Ink hairline underneath. Slide gutter is 120 px; page number sits top-right in muted caps.
