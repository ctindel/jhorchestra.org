Media chip / tag. The glyphs are bare unicode characters — this brand has no icon font, so use these exact ones.

```jsx
<Chip tone="subway"  glyph="▦">Poster</Chip>
<Chip tone="tandoor" glyph="⛁">Program (PDF)</Chip>
<Chip tone="hibiscus" glyph="▶">2 videos</Chip>
<Chip outline>Brahms, Symphony No. 2</Chip>
<Chip muted>no recording</Chip>
```

Glyph map: ▦ poster · ⛁ program · ▶ video · ♪ audio · ◉ photos · ✎ notes.
