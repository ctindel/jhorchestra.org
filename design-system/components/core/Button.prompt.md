Pill-shaped action button — use for every clickable action in JHO surfaces; never build a square button.

```jsx
<Button variant="donate" size="sm">Donate</Button>
<Button variant="primary" arrow>Learn more</Button>
<Button variant="secondary">About the Orchestra</Button>
<Button variant="ghostDark">Directions</Button>
```

Variants: `primary` (Ink fill — the default site CTA), `donate` (Tandoor fill — donate + sponsor), `secondary` (Ink outline on light), `ghostDark` (paper outline on Ink grounds). Sizes `sm|md|lg`. `arrow` appends the house "→" used on forward actions.
