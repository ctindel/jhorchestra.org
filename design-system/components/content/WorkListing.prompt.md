A programmed work on a poster, program or concert page.

```jsx
<WorkListing composer="Michael A. Lee" work="Cognōscent" tag="World Premiere" />
<WorkListing number="02" composer="F. Mendelssohn" work='Symphony No. 5 "Reformation"' />
```

Composer surnames come first; the work is always italic; premieres get a tag rather than an exclamation point. The tag sits **inline with the work title**, baseline-aligned, wrapping to the next line only if there isn't room.
