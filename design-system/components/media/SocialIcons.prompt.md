The only real icon set in the JHO brand — YouTube, Facebook, Instagram, X, as solid single-path SVGs.

```jsx
<SocialIcons />
<SocialIcons networks={['instagram','youtube']} tone="dark" />
```

Rest at 0.55 opacity, hover to full opacity + Tandoor. Everything else in this brand that looks like an icon is a unicode glyph (see `Chip`) — never add Lucide, Heroicons or an icon font.
